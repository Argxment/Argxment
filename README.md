# Привет, я Slava! 👋

### Обо мне 👨‍💻
Я — увлеченный **Full-stack разработчик** с крепким фундаментом в области программной инженерии. Сейчас я нахожусь на этапе активного расширения своего технологического стека, совмещая учебу в колледже с созданием собственных проектов.

* 🛠 **Backend & Core:** Имею опыт работы с **C#**, **C++** и **Python**, что позволяет мне быстро адаптироваться под разные задачи — от высокопроизводительных вычислений до автоматизации процессов.
